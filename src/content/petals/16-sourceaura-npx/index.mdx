# sourceaura-npx

The business card, for the terminal.

`npx sourceaura`: run it anywhere Node lives and get the card: who I am, where to find me, what I'm about. No website required, no loading spinner. Just the terminal, which is where I live anyway.

Oldest trick in the dev playbook, and still the coolest handshake.
