# Gedachte - RealTime Chat. 💭

> Gedachte - ...share the essence of imagination. 💭
> — the 2019 original

Gedachte is Dutch for "thought." The original was a realtime chat app — messages in a bottle, set adrift. Vue, Quasar, Firebase, 2019. It worked, but the toolchain rotted and the todo list — profiles, DMs, route guards — never got finished.

So instead of porting it, I rebuilt it. Same bottle, new ship: Astro, bun, TypeScript, a fresh Firebase project. The 2019 todo list is finally getting done.

The original still floats at its Netlify address — an archive, barnacles and all. The rebuild lives at the repo above.
