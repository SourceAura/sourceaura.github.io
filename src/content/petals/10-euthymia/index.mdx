> A multiplayer web game with a soul — and a security layer.

**Euthymia: Soul Alterz** is a full client/server multiplayer web game I'm
building toward publish: web first, then PWA, itch.io, and Steam.
Free-to-play, never pay-to-win — the design doc says it plainly: *sell
identity, never power.*

## The world

Protocol War lore. Three races — Shardborn, Ghostborn, Qi-born — two
factions, Sanctum base building, an Archivist shop, and a QC economy.
The vertical slice is ~85%: the core loop and multiplayer are live.

## The engineering

- **TypeScript client + server**, real client/server architecture with a
  live connection between them.
- **GitHub + Discord OAuth, fail-closed** — verified working, secrets in a
  gitignored `.env`, auth that refuses to run misconfigured.
- **The Yokai loop** — gamified ethical hacking as a game mechanic: scan →
  analyze the vulnerability → synthesize a patch → deploy it → earn the
  bounty. Security *is* the gameplay.
- **Security-before-deploy discipline** — the server is a monolith with no
  persistence yet, and it stays private until validation, auth hardening,
  and tests are in. No shipping secrets.
