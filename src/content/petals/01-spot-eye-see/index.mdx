## a good place to start...

As an avid music listener, exploring the Spotify API is a no brainer...
And well...we gotta start somewhere right.

---

> A note from 2021: start where the love is.

I'd been an avid listener my whole life: it was only a matter of time before I started taking the music apart. The Spotify API was one of my first real APIs: real auth, real data, real rate limits. A listener learning to speak the language underneath the songs.

"We gotta start somewhere, right?" Right. This was somewhere. Every integration since (every OAuth dance, every third-party API) started here, with me asking an API about my own listening and getting an answer back.
